# 📌 Descripción

Este proyecto consistió en el desarrollo e implementación de un sistema de automatización para una *planta de tratamiento de aguas residuales* ubicada en *Querétaro, México, utilizando un **PLC Delta* programado en *ISPSoft* y una *interfaz HMI desarrollada en DOPSoft*.

La automatización permitió supervisar y controlar el proceso de tratamiento mediante una interfaz gráfica intuitiva, optimizando la operación de la planta y reduciendo la intervención manual del operador.

---

# 🎯 Objetivos

- Automatizar el proceso de tratamiento de aguas residuales.
- Controlar el funcionamiento de bombas.
- Supervisar medidores de flujo.
- Visualizar variables del proceso en tiempo real.
- Mejorar la eficiencia y seguridad de la operación.
- Facilitar el diagnóstico de fallas mediante alarmas.
